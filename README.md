# myts for Kindle 3 with KUAL

A terminal for the Kindle based on
[http://my.svgalib.org/kindle/myts-8.zip](http://my.svgalib.org/kindle/myts-8.zip),
with fixes and preferences that make it usable as a primary display device.

This fork targets the **Kindle 3** and **KUAL**. It does not use launchpad. The
binary is ARMv6/EABI5, **soft-float**, statically linked with musl.

## Quick start

### Use the prebuilt binary

1. Copy `kual/extensions/myts` to `/mnt/us/extensions/myts` on the Kindle.
2. Open KUAL and enter **MyTS Terminal**.
3. Choose **Terminal 1**.

If you prefer a zip, run `make zip` and extract `dist/myts-kual.zip` at the root
of the Kindle.

### Build and package

On Linux x86_64 with `make`, `curl`, `tar` and `zip`:

```sh
make k3      # downloads the toolchain if needed, builds and updates the extension
make zip     # creates dist/myts-kual.zip
```

The compiled binary is installed at `kual/extensions/myts/bin/myts`.

## Quick usage guide

Open **KUAL → MyTS Terminal → Terminal 1**. The terminal appears after about
3 seconds. To leave the terminal, press the key configured as `TermEnd`
(`Right<` by default), or use **Stop MyTS** from KUAL.

### Numbers

Hold **Alt** and press the first QWERTY row:

```text
Alt + q w e r t y u i o p  ->  1 2 3 4 5 6 7 8 9 0
```

### Symbols

Hold **Back** (the default `TermSym` key) and press:

```text
Back + q w e r t y u i o p  ->  ! @ # $ % ^ & * ( )
Back + a s d f g h j k l D  ->  ' + # - _ ( ) & ! ?
Back + z x c v b n m .      ->  ~ $ | / \ " ' :
```

If you prefer the physical **Sym** key as the symbol modifier, set this in
`kual/extensions/myts/bin/myts.ini`:

```ini
TermSym = Sym
TermLang = Back
```

For the complete keyboard map, see [docs/USAGE.md](docs/USAGE.md).

## Repository layout

```
src/                    C sources and headers
src/linux/              Kindle eink framebuffer kernel headers
kual/extensions/myts/   ready-to-copy KUAL extension (includes the binary)
tools/bdf2hex           BDF-to-hex font converter
Makefile                build and packaging
README.md               this document
AGENTS.md               guide for agents and contributors
docs/                   detailed documentation
build/                  generated by make (ignored)
dist/                   zip generated by make (ignored)
toolchain/              toolchain downloaded by make (ignored)
```

## Requirements

- Kindle 3 with jailbreak and KUAL installed.
- No build is required to use the prebuilt binary.
- To build on Linux: `make`, `curl`, `tar` and `zip`.
- The native ARM build requires `musl-gcc`.
